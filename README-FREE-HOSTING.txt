BUTTERFLYTAMILCHAT — FREE HOSTING

This package is prepared for a free Render Web Service.

WHAT YOU NEED
1. A free Render account.
2. A GitHub account.
3. Upload this folder to a GitHub repository.
4. In Render choose New -> Web Service.
5. Connect the GitHub repository.
6. Use:
   Build Command: npm install
   Start Command: npm start
   Plan: Free
7. Deploy.

Render gives the service an onrender.com web address. Free web services can host Node/Express apps and support WebSockets, which this chat uses.

IMPORTANT
- Free services can sleep after inactivity and can take about a minute to wake up.
- Do not put passwords or API keys in this package.
- For reliable video calls across all networks, add a TURN server later.
- HTTPS is provided by the hosting platform.
- FM requires your own/legal stream URL.
